# **App Name**: ParkX

## Core Features:

- Vendor Management: Super Admin invites, approves/denies, and manages vendors, including setting parking spot limits.
- User Management: Vendor Admins invite and manage end-users, including assigning spots and updating profiles.
- Parking Spot Management: Vendor Admins define parking lots by adding, renaming, and removing parking spots. End users can request and manage parking spots.
- Role-Based Access Control: Defines access based on Super Admin, Vendor Admin, and End User roles.
- Communication Portal: Messaging portal for Super Admin to Vendor Admin, and Vendor Admin to End User communication.
- AI Conversation Summarization: AI tool summarizes conversation threads between Super Admin and Vendor Admins.
- Subscription Management: Financial oversight, subscription settings for vendors, invoice history, and platform-wide payment configurations.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability.
- Background color: Light gray (#EEEEEE) for a clean and professional look.
- Accent color: Soft purple (#9575CD) to highlight key actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, neutral look. 'Inter' is suitable for both headlines or body text
- Use consistent and professional icons for parking spots, user profiles, and management tools.
- Clear, role-based dashboards with easy navigation for Super Admin, Vendor Admin, and End Users.
- Subtle transitions and feedback animations on user interactions.
